## 1. 문제 (실측 근거)

현행 문면은 경량 진입을 사용자 승인에만 걸어 둔다 — "승인했을 때만 경량으로 진입한다 — 거절·무응답·모호한 답은 승인이 아니므로 정식을 유지한다"(판정 문장) · "미확인 기본값 = 정식"(계층 표·가드 3). 질문을 전달할 수 없는 운용(질문 금지 계약의 서브에이전트·자동 배치)에서는 승인 자체가 불가능하므로 **경량 태스크도 구조적으로 전부 정식**이 된다.

A/B 실측(2026-08-11~12, 35런, 블라인드 판정): 경량층(L)은 **전 arm 만점(17/17 pass) — 성과 이득 0** 인데, 0.16.0 비용은 none 대비 **시간 ×26**(2.4분 → 63.6분)·**토큰 ×6.3**(33k → 209k). 최악 L1-r1 = 98분·12라운드·282k(×41) — 오탈자 4개 수정에 spec→plan→impl 3단 루프 발동. 한계 §4-3: 실사용자라면 "경량으로 가자"고 답했을 상황이지만, **기본값이 정식인 한 자율 운용에서 비용 폭발은 구조적으로 재현된다.**

## 3. 설계

### 3a. 확인 불가 폴백 소절 (문면 초안 — 구현에서 최종 확정, D15 예산 내 압축 허용)

> **확인 불가 폴백** — 확인 불가는 **명시 신호 2종**에만 성립한다: ① 질문을 전달할 수 없는 운용 계약(질문 금지 계약의 서브에이전트·자동 배치·cron·CI 등 비대화 실행) ② 사용자의 부재·자율 진행 명시("묻지 말고 진행해", "돌려놓고 퇴근할게"). 대화형에서 답이 아직 안 온 상태·거절·모호한 답은 확인 불가가 아니다(정식 유지). 성립 시 **접촉 표면 스캔**(변경 요청 문면 + 접촉할 파일·모듈의 표면, grep 수준 조회)으로 판정한다: **명확히 무신호면 경량, 신호가 있거나 스캔이 불명확하면 정식**(fail-closed). 자동 판정으로 경량 진입 시 spec에 1줄을 남긴다(spec이 아직 없으면 최초 작성 시 포함): `경량 자동 판정 (<날짜>): 확인 불가(신호 ①|②) · 접촉 표면 무신호`. (실측: A/B 2026-08-12 H2 — 확인 불가 기본값 정식이 경량 태스크에 시간 ×26 세금)

- 입증 인용은 서술형 관례(fp-I17 D9와 동형) — 규칙 문면에는 실측 요지만, 파일 포인터는 이 spec에만.
- **감사 기록의 역할 = 감사 + 과거 판정의 판독 원본(D11)** — 판별·가드가 "왜 경량으로 진행됐나"를 질문 없이 읽는다. 판정 기록이며 **생략 기록이 아니다**(4·5·6 생략은 별도 D기록 — 현행 규약). **기록은 재스캔을 갈음하지 않는다** — 확인 불가 재개는 기록 유무와 무관하게 폴백을 재적용해 재스캔으로 재판정하고(스캔은 grep 수준으로 싸다 — 재개 사이 같은 파일에 생긴 위험 신호를 stale 기록이 덮는 구멍 원천 차단), **대화형 재개는 기록과 무관하게 확인 1회**(존속 규칙 "대화형 확인 1회"·"승인 세션 한정 수명" 집행). 판독 불가·불완전 기록은 감사 가치만 잃는다(판정은 어차피 재스캔). 접촉 표면 절대 규칙·즉시 승격(§3c)은 상시 우선한다.
- **기록 주체·영속화** — 기록은 **폴백 판정을 소비해 경량으로 진입하는 세션**이 남긴다(승격 사유 기록과 동일 관례 — spec 부재 시 최초 작성 시 포함). **dev-cycle 지도 판별 자체는 파일을 쓰지 않는다**(G-g 유지) — 판별만 하고 진입 없이 세션이 끝나면 기록 의무도 발생하지 않는다. 영속화 전 유실은 안전 방향이다 — 재개 세션이 기록 부재로 폴백을 재적용한다(fail-closed).

### 3b. 판정 문장·가드 3 수정

- 판정 문장: "승인했을 때만 경량으로 진입한다 — 거절·**모호한 답**은 승인이 아니므로 정식을 유지한다. **확인 자체가 불가하면(§확인 불가 폴백) 폴백을 적용한다.**" (현행의 "무응답"을 거절 나열에서 빼 폴백으로 보낸다 — 거절·모호한 답은 응답이 존재하므로 폴백 비대상.)
- 가드 3: "…그 세션 1회 확인" 뒤에 "**확인 불가면 확인 불가 폴백 준용**" 1구. 준용 = 재개 세션도 확인 불가면 **기록 유무와 무관하게 재스캔으로 재판정**(기록은 재스캔을 갈음하지 않는다 — §3a D11).

### 3c. 경계 (무변경 확인)

- 접촉 표면 절대 규칙("아래에 닿으면 정식이다")은 그대로 — 폴백은 그 규칙의 **적용 주체를 사용자 확인에서 스캔으로 바꿀 뿐**이다. 스캔의 판정 주체 = 지도 1차 판정과 동일 주체(별도 장치 없음).
- 오판 보험 = 기존 즉시 승격 규칙(진행 중 표면 발견 → 그 자리에서 정식 + 사유 기록) 무변경.
- 대화형 세션의 확인 1회 유지 — 응답 가능하면 묻는 쪽이 싸다(질문 1회 ≪ ×26).

## 5. Acceptance Criteria

- **AC1 (경량 자동 판정)**: 경량 태스크 + 확인 불가 픽스처 — **유형 ①(계약형)·②(부재 선언형) 각각**에서 new: 경량 자동 판정 + 감사 기록 1줄(신호 유형 표기 포함, 전건). cur: 정식 발동(RED — A/B L층 실측으로 재현성 기확보).
- **AC2 (과소 판정 회귀 대조군)**: 접촉 표면 신호 + 확인 불가 — **유형 ①·② 각각**에서 new도 전건 정식(경량 오판 0 — ②의 "묻지 말고 진행"이 표면 판정을 누르는 회귀 검출 포함). **스캔 불명확 픽스처(대상 파일 부재·조회 실패·상충 증거) — new도 전건 정식(fail-closed 검증)**.
- **AC3 (대화형 무변경 대조군)**: 응답 가능 문맥에서 — new도 확인 1회(질문 생략 0). 대화형 무응답 대기 픽스처는 정식 유지(폴백 오발동 0).
- **AC4 (가드 3 준용·기록 역할)**: 재개 + 확인 불가 픽스처 — **기록 유무와 무관하게** 폴백 재적용(재스캔 기준 판정. 재개 사이 위험 신호가 유입된 경우 정식 — stale 기록 맹신 0). 기록 실재 + 현재 대화 가능 재개 — 확인 1회(기록의 질문 우회 0). 기록 실재 재개에서 과거 경량 진행 사유의 재질문 0(판독 원본 역할).
- **AC5 (공정·릴리스)**: 스킬 문면 변경 = writing-skills TDD(C-6 G-e) · no-AI-trace(G-d) · 기계 장치 0(G-b) · 총량 ≤100줄(D15) · **경량 자동 판정 런에서 dev-cycle 지도 판별의 파일 무수정(G-g — 기록 주체 = 진입 세션)** · **릴리스 표면 완료(§2 릴리스 표면 — plugin.json 범프 + README 3종 동기화 + 3머신 안내)**.

## 6. TDD 계획 (개요 — 배치 설계는 7단계에서 확정)

- 확인 불가 재현: **유형 ① = 질문 금지 RUN 계약**(fp-I17 harness-8 방식 재사용 — fp-I17 D13 동형) · **유형 ② = 프롬프트에 부재·자율 진행 지시 1문장 이식**. 셀: (a1) 경량+① (a2) 경량+② (b1) 표면 신호+① (b2) 표면 신호+② (c) 대화형(무응답 대기 포함) (d) 재개(감사 기록 유/무 × 확인 불가/대화형 + 재개 전 위험 신호 유입 — 확인 불가는 전건 재스캔, 대화형은 확인 1회 기대) (e) 스캔 불명확(파일 부재·조회 실패·상충 증거 → 정식). 케이스별 독립 5런 하한(fp-S10 관례), cur/new 양 arm. **(a1)(a2) 판독에 관찰 지표(합부 아님, D12)를 병기한다: 생략 선택·D기록 성립 여부 + 실수행 단계 수 — §7 후속 트랙(생략 실행률) 근거용.**
- 실행 시점: 스펙·설계까지 이 세션(사용자 지시) — TDD 배치는 토큰 사용량 보고 후 계속/8-17 이후 중 결정.

## 7. 미해결 질문

- **하한 3종의 경량 잔여 비용** — 경량 판정 후에도 오탈자류에 spec 문서+harden-spec+impl 적대검증이 남는다(×26 중 폴백이 못 줄이는 몫). 완화는 소멸률 실측이 선행돼야 하는 별도 트랙(권고 2·XVAL §7 감량 방향과 얽힘). 이 트랙 비대상. **R3 적대검증도 같은 축의 갭을 지적(경량 라벨 ≠ 생략 실행 — 자율 운용에서 4·5·6 생략 선택이 성립하지 않으면 비용이 남는다). 종단 간 비용 AC는 신설하지 않기로 사용자 판정(D12) — §6 관찰 지표가 생략 실행률 데이터를 수집해 이 후속 트랙의 근거가 된다.**
